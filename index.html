About Me

데이터를 읽고, 콘텐츠로 실행하며, 성과로 검증하는 마케터

소비자의 관심이 어디에서 시작되고, 어떤 콘텐츠에 반응하는지 데이터를 통해 확인하고 이를 실제 콘텐츠 기획으로 연결해왔습니다. 검색 키워드와 콘텐츠 성과를 분석해 트렌드성 콘텐츠를 기획하고, 발행 후 조회수와 유입 데이터를 다시 분석해 다음 콘텐츠에 반영했습니다. 또한 글로벌 프로젝트 운영 경험을 통해 다양한 이해관계자와 일정·품질·비용을 조율하며 기획한 일을 실제 결과물로 완성하는 실행력을 갖추었습니다. 이제는 이러한 데이터 기반 사고와 운영 경험을 온라인 광고와 콘텐츠 마케팅으로 확장하고자 합니다.

Core Strength

세 가지 축의 완벽한 교집합

DATA

데이터를 통해 소비자의 관심을 발견합니다.

네이버 검색량, 연관 키워드, 계절성 및 콘텐츠 조회 데이터를 활용해 소비자가 무엇을 찾고 있는지 분석합니다. 단순히 인기 키워드를 따라가는 것이 아니라 검색 데이터 → 소비자 관심 → 콘텐츠 가설 → 성과 분석으로 연결하는 방식으로 콘텐츠를 기획해왔습니다.

CONTENT

데이터를 콘텐츠로 바꾸는 기획력을 갖추고 있습니다.

트렌드 키워드를 발견한 후 타깃 고객을 설정하고, 검색 의도에 맞춰 제목·구성·정보를 설계해 콘텐츠를 제작했습니다. ChatGPT, 이미지 생성 AI, Canva 등의 도구를 활용해 아이디어 도출부터 콘텐츠 제작까지 빠르게 실행하고 테스트했습니다.

OPERATION

기획을 실제 결과물로 완성하는 실행력이 있습니다.

글로벌 프로젝트에서 발주처·협력사와의 커뮤니케이션, 일정 및 품질 관리, 비용 모니터링을 담당했습니다. 여러 이해관계자와 동시에 업무를 조율하며 일정 관리 → 이슈 대응 → 결과 확인까지 프로젝트를 끝까지 운영해본 경험이 있습니다. 온라인 마케팅에서도 캠페인 일정, 콘텐츠 제작, 매체 운영 및 성과 관리가 유기적으로 연결되어야 한다는 점에서 이러한 운영 경험을 강점으로 활용할 수 있습니다.

[ 01 · Data-driven Content Marketing ]
Personal Marketing Project (2026)

검색 데이터를 활용한 소비자 인사이트 기반 콘텐츠 기획

Problem
검색 트렌드가 빠르게 변화하는 환경에서 소비자의 관심사를 데이터 기반으로 선제적으로 파악할 필요.
Action
네이버 검색량, 연관 키워드, 계절성 데이터를 분석해 키워드를 선정하고 SEO 기반 콘텐츠를 기획·발행. 발행 후에는 조회수, 유입 키워드 등 성과 데이터를 분석해 다음 기획에 반영 가설 수립.
Result
150편 이상의 콘텐츠를 기획·운영했으며, 트렌드 초기 키워드를 활용한 콘텐츠는 조회수 1,000회 이상을 기록. 성과 분석을 기반으로 재현 가능한 콘텐츠 기획 프로세스를 구축.
Learning
시장 데이터를 소비자 인사이트로 전환하고, 이를 기획으로 연결하는 마케터의 사고방식을 체득.

[ 03 · Project Operation ]
HD현대중공업 · 글로벌 해양플랜트 프로젝트

글로벌 프로젝트에서 쌓은 운영 및 커뮤니케이션 역량

Problem
글로벌 프로젝트 진행 과정에서 다수의 발주처와 협력사가 참여하며 일정·품질·비용 및 커뮤니케이션 이슈를 동시에 관리.
Action
발주처 및 협력사 커뮤니케이션을 담당하고 프로젝트 일정과 계약 조건, 비용 및 품질 이슈를 지속적으로 모니터링. 협력사의 업무 수행 현황을 관리하고 이슈 발생 시 관련 부서와 조율하며 프로젝트가 계획대로 진행될 수 있도록 지원.
Result
4건의 글로벌 프로젝트 운영 지원 프로젝트 기간 동안 발주처 대응 및 협력사 관리 업무를 수행했으며, 3년간 중대클레임 0건의 안정적인 프로젝트 운영 경험을 쌓았습니다.
Learning
온라인 마케팅 역시 여러 매체, 콘텐츠 제작자, 디자이너, 클라이언트 등 다양한 이해관계자가 동시에 움직이는 업무라는 점에서, 프로젝트 운영 과정에서 쌓은 커뮤니케이션·일정관리·이슈 대응 역량 활용 가능.

WHY 이지엠엔씨?

데이터로 소비자를 이해하고, 콘텐츠로 성과를 만드는 마케터가 되고 싶습니다.

'무엇을 만들 것인가'보다 '왜 이 콘텐츠를 만들어야 하는가'를 먼저 찾는 것​

검색 데이터와 소비자 반응을 통해 관심사를 발견하고, 이를 콘텐츠와 마케팅 메시지로 구체화한 뒤 실제 성과를 확인하고 개선하는 과정을 경험해왔습니다. 이지엠앤씨의 메디컬 마케팅 업무에서도 이러한 데이터 기반 사고를 바탕으로 시장과 소비자의 반응을 빠르게 파악하고 싶습니다. 입사 초기에는 네이버·구글·메타 등 주요 온라인 채널의 특성과 광고 운영 방식을 빠르게 익히고, 콘텐츠 제작 및 캠페인 운영 과정에서 실무 역량을 쌓겠습니다. 이후에는 캠페인 데이터를 단순히 보고하는 데 그치지 않고 매체별 성과와 소비자 반응을 분석해 다음 콘텐츠와 광고 전략으로 연결할 수 있는 마케터로 성장하겠습니다. 특히 제가 경험해온 검색 데이터 분석과 콘텐츠 기획 역량에 AI 도구를 결합해 더 빠르게 다양한 콘텐츠를 테스트하고, 성과가 검증된 방향을 중심으로 마케팅 효율을 높이겠습니다. 장기적으로는 광고 운영과 콘텐츠 기획, 데이터 분석을 하나의 흐름으로 연결해 고객의 관심을 실제 전환과 브랜드 성장으로 이어지게 만드는 마케팅 전문가가 되고 싶습니다.
